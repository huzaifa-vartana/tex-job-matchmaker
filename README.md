
# TeX Job Matchmaker

## Overview

TeX Job Matchmaker is an AI-powered tool that helps you tailor your LaTeX resume for specific job applications, increasing your chances of getting an interview. The application analyzes your existing LaTeX resume alongside job descriptions and intelligently modifies your resume's content to highlight relevant skills and experiences while preserving your personal information, employment history dates, and education details.

## Key Features

- **LaTeX Resume Upload**: Upload your existing LaTeX resume format
- **Job Description Input**: Paste job descriptions or provide job URLs
- **AI-Powered Tailoring**: Uses advanced AI models to customize your resume
- **Multiple AI Model Support**: Choose between OpenAI or Groq for resume processing
- **Preview & Compare**: View your original and tailored resumes side-by-side
- **Easy Download**: Download your tailored LaTeX resume file
- **Secure Processing**: Your API keys are stored locally in your browser

## Tech Stack

This application is built with modern web technologies:

- **Frontend Framework**: React with TypeScript
- **Build Tool**: Vite for fast development and optimized production builds
- **Styling**: Tailwind CSS for responsive and utility-first styling
- **UI Components**: ShadCN UI for accessible, customizable components
- **AI Integration**: Support for both OpenAI and Groq AI models
- **State Management**: React's Context API and useState hooks
- **File Processing**: Client-side LaTeX parsing and manipulation
- **Local Storage**: Browser localStorage for API key management
